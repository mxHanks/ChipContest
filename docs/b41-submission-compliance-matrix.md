## 官方硬约束与当前材料状态

| 官方条款 | 正式提交必须满足 | 当前材料状态 | 新稿处理 |
|---|---|---|---|
| DMA 集成 | DMA 进入原有 SoC 系统框架 | 现有架构说明使用 `xu_matrix_dma64` | 只保留为迁移前诊断，正式架构改写为原 System Bus |
| 参数加载 | X/W/bias 均通过正式接口传输，加载时间计入 | 现有材料已有真实 DMA 事务统计，但为 64-bit | 重新绑定到 32-bit beat 序列后才可宣称 |
| 样本精度 | 统一随机 600 样本 | 当前材料未提供 600 样本正式回执 | 标记“待补”，不得写成已完成 |
| 总线位宽 | 平台总线和加载接口保持 32-bit | 当前 PPT/报告明确写 DMA64、64-bit 写回 | 从主叙事移除；32-bit 作为唯一正式目标 |
| 共享 SRAM | 必须走规定共享 SRAM 通路 | 当前材料含 64-bank × 4-lane 组织和 DMA64 接入 | 不把 bank 并行解释成合规外部接口 |
| TCM 绕过 | 不得直接访问 ITCM/DTCM | 当前材料未把 TCM 作为主加载路径 | 保留检查项并补断言/日志 |
| 独立通路 | 禁止流式旁路、独立 SRAM 写口和 TB 专用装载 | 当前材料描述 64-bit DMA 和独立 lane 组织 | 正式稿只描述原 System Bus 请求/响应 |
| 输出存储 | 完整保存 99×256 Y32 | 当前 64-bit 版本逐位比较通过 | 结果可作为数值证据，但需与 32-bit 版本重新绑定 |
| 位宽收窄 | ACC/结果/FIFO 41-bit 有完整范围证明 | 当前已有理论范围和 RTL 片段 | 可保留，注明其不等于总线合规 |
| 时序 | 声明 PVT/RC 条件下实际闭合 150 MHz | 当前是理想时钟四场景与补查证据 | 只写已验证场景；完整生命周期缺口显式列出 |
| 功耗/能耗 | 全 SoC 活动窗口、统一单位、同一冻结配置 | 当前材料写明仍在测量 | 不写最终能耗、不提前选固件 |
| 固件冻结 | 性能/面积/功耗/精度必须来自同一配置 | 当前有三份 DMA64 冻结固件 | 作为候选诊断基线；正式选型待 32-bit/功耗结果 |
| 提交材料 | 报告、≤3 分钟 H.264 视频、声明、照片等 | 报告 8 页，视频 H.264 129.6 秒；照片/签字声明待核 | 可先重制报告/PPT/清单，缺件单独列为用户补交项 |

## 当前可安全使用的证据

### 可作为工程事实

- 64 PE、8×8 行列并行结构。
- signed16 输入/权重、signed40 bias、41-bit 内部累加、Y32 舍入语义。
- `99×256` 完整输出的数值模型和逐位比较方法。
- 三份固件在 DMA64 B41 仿真/门级适配副本上的 12 任务与 warmup 记录。
- 现有 Formality、面积、理想时钟 STA 和低频边界补查的限定范围。

### 只能作为诊断或历史基线

- `DMA64`、64-bit 读写、4-lane 同拍访问。
- 4196.64 task/s、428,916 周期等基于 DMA64 版本的吞吐数字。
- 任何尚未完成覆盖率、单位审核和同一冻结配置绑定的功耗/能量数字。
- 现有报告中以 `xu_soc_dma64_ppa_top`、`xu_matrix_dma64` 为正式顶层的表述。

### 当前缺口

1. 生产 RTL/固件切回原生 32-bit System Bus。
2. 重新生成并封存 32-bit X/W/bias/Y 事务、golden、固件和 SHA manifest。
3. 证明没有 TB-only preload、TCM bypass、独立写回或流式旁路。
4. 在 32-bit 冻结版本上重跑 RTL、VCS、门级、等价、STA、面积、功耗和 600 样本精度。
5. 补齐队伍/个人照片、签字 IP 声明及最终上传清单。

## 四小时执行顺序

1. 先锁定 32-bit 合规口径和证据分层，停止继续扩写 DMA64 主叙事。
2. 生成 10–12 页评审型 PPT：任务 → 合规数据通路 → 计算核 → 验证证据 → 已完成/待补 → 提交边界。
3. 用同一口径重写报告摘要、架构图、验证表和提交核对说明。
4. 将现有 MP4 做为视频素材候选，检查画面中是否出现学校名、DMA64 主张或未验收功耗结论。
5. 形成 `SUBMISSION-CHECKLIST.md`，把缺失照片、签字声明、32-bit 重跑结果作为明确阻塞项。

该顺序的目标是四小时内得到可审查、可复现、不会误报的提交包；它不把尚未完成的 32-bit 工程验收伪装成已经完成。

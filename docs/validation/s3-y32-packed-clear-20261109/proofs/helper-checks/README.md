# Public PACK32 physical-clear helper validation

Final helper SHA256: `fbd013b9b0c8de9f7c2d6e0c76cc8676aaabf6436b5835f2a8046072d589533d`.
Final test SHA256: `3868a850a72c8420cefeda4022b74c3c1707e28f30411bb1fde5b5abd9dc36c9`.
The old scalar helper is unchanged, SHA256 `153c429556dbea7e8ebdbf0be4514d23776f8bc449fbd3ead57ee5cdd831c16f`.
All selected RTL files remain byte-identical to the production input; `final-source-pins.json` pins 60 source inputs. No synthesis, production edit, internal DUT assignment, `force`, or memory preload is used.

The helper C uses the public MMIO interface: disable cache once, set W cursor to 0 once, issue 8,192 zero W_PACK32 commands, run the unchanged bias clear and eight legacy 40-bit bias clears, set X cursor to 0 once, and issue 32 zero X_PACK32 commands. Six initial ABI reads include exact STREAM_CAP and PACKED_CAP checks. After `fence iorw, iorw`, STREAM_STATUS must be 0, then STATUS must be 0. SRAM mode has 8,252 accepted writes, 8 accepted reads and 8,260 command/response pairs. The old scalar mode has 32,930 writes and 32,935 command/response pairs. Physical work remains 16,384 W words, 64 X entries, 768 full 16-bit bias words, 640 bias staging bits, and 320 legacy bias bits.

The W cursor is row-major logical element p: row=p/256, column=p%256; bank=column%8; physical address=(column/8)*64+row. Even p and p+1 write adjacent banks at the same physical address. Each WeightBank splits the physical address at bit 10 into two 1024x16 memories. The macro half is therefore cursor bit 7, not a split at cursor 8192. Independent enumeration proves each of 16 macro×1,024 addresses appears exactly once.

The passive observer checks every actual `u_linear_compute_core.io_wLoadWen` / `io_xLoadWen` sampled edge, zero data, independent order and unique bank/address coverage. A separate bitmap checks all 16 real W macro RW0 enable/write-mode/address/data pins and exact cardinality against core writes. Bias coverage is 768 independent actual macro write edges, not a count inferred from the command or `clearDone`. Each packed response retires only after exactly two actual downstream writes; the W macro count agrees with the actual core count. The final proof and the first source VALID predicate require no pending command, response, stream/cache work, core write strobe or active physical memory port. All W/X/bias/legacy/staging final values are inspected read-only.

The real-wrapper probe deliberately initializes all operand storage through public MMIO before arming the observer. W and X use the independent scalar bank/address interface rather than the packed mapping being tested. Before arming, every one of the 16,384 W macro positions, 64 X registers, 768 bias physical words and eight 40-bit legacy values is checked for an exact known nonzero value. A preliminary public BIAS_CLEAR initializes the unused high byte of every third bias word, then public 40-bit writes set every valid bias bit nonzero: word0=4938, word1=6b5a, word2=0027. Thus the valid low byte of word2 is nonzero while padding remains known zero. Public manual group 0 and 1 computations fill both staging slots; all 16×40 staging bits are checked nonzero before the measured clear. No unknown value is treated as nonzero. The clear then proves all 768 full 16-bit words, including padding, and all 640 staging bits are zero.

The positive path checks every pair's first physical edge has no response and second physical edge precedes response, then holds responses blocked for two cycles without replay. Three reset boundaries abort after acceptance, after the low physical write, or after both writes with a blocked response; actual SRAM work is checked, all locations are publicly refilled, and a new complete proof is required. Atomic error cases cover incomplete masks, odd cursors, terminal bounds and busy writes, followed by a full nonzero prestate check and complete clear. Negative protocol modes omit W or bias work, mask a write, write nonzero low/high halves, repeat a cursor/address, request proof too early, omit the two completion reads, or present source VALID while a pair/bias/response is pending. No source READY handshake is necessary to reject an early source.

Three explicitly isolated RTL fault-injection copies validate that the proof detects real missed physical work after nonzero prefill: suppress bank 7 zero writes, suppress X address 0 zero writes, or suppress legacy high-byte zero writes. These are negative probe artifacts, not production RTL or full-SoC results. Mutation JSON records exact original and changed source hashes. The production RTL is untouched.

The register-bias fallback generator remains available but is not the selected campaign. Its optional real generated-RTL test requires `S3_REGISTER_BIAS_RTL_DIR`; when unavailable, the test explicitly skips rather than substitutes a DUT or claims validation. This native probe is not a full-SoC, vendor macro, mapped timing, power, or official policy qualification. `fifo_payload_physical_zero=UNPROVEN` and `policy=REVIEW_PENDING` retain their original meaning.

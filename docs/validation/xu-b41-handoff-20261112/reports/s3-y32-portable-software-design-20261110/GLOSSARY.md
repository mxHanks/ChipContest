# FFN 加速器通用软件优化

本词汇表用于当前 64 PE 硬件与软件并行开发的设计讨论。

## Language

**通用软件候选**：
可在不同加速器版本中复用设计和源码的软件优化方案；其兼容性与收益需要在对应硬件分别验收。
_Avoid_: 在所有 PE 配置上都最优的软件

**硬件定向软件候选**：
依赖某个加速器版本具体能力或数据组织的软件优化方案。

**完成发现延迟**：
从加速器完成当前性能任务，到软件确认该任务已完成的时间。
_Avoid_: 加速器计算时间

**完成上报延迟**：
从加速器完成当前性能任务，到软件完成向外部发布该任务完成状态的时间。

**软件配置复用**：
在硬件与工作负载前提适用时，沿用某次软件策略选择的参数；它比复用软件源码要求更强的适用性证据。

**64 PE 验证结果**：
绑定实际 64 PE 设计与对应输入、软件和验证条件得到的结果。
_Avoid_: 用更短模拟等待时间代表 64 PE 实测

**固定软件配置**：
在一次已冻结的性能或能耗评测中保持不变的软件策略及其参数，其适用范围绑定对应硬件版本和任务条件。
_Avoid_: 正式任务运行期间自动学习产生的新配置

**固定硬件软件优化**：
对既定加速器能力、任务规则和数值语义保持兼容的软件改进。
_Avoid_: 将需要新增硬件能力的方案称为纯软件改进

**软件开发验收**：
在绑定硬件版本和开发工作负载上，确认软件正确性与运行表现的验收；其结论限于对应的开发条件。
_Avoid_: 官方准入通过

**软件得分选型**：
在资格和测量口径一致的条件下，依据官方评分规则比较软件候选并选定最终配置的决策。
_Avoid_: 按CPU活动计数选出能耗冠军

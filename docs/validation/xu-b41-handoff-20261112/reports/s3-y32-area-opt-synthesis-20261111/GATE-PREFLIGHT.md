# B41 门级接入核对

这是门级运行前的输入核对，尚无本版门级通过或能耗结果。机器可读记录见 [gate-preflight-r1.json](gate-preflight-r1.json)。三份固件的实际 ELF／映像 SHA 和七个相关源码已核对，冻结软件输入未修改。

当前电气候选为 `f73b4518…`，仍有电气违例，且尚未完成该版本等价。门级工程最终必须绑定修复后实际选定的网表。

| 接入项 | 已核对事实 | 下一项原生检查 |
|---|---|---|
| PPA 边界 | 顶层 `xu_soc_dma64_ppa_top` 内含 `u_soc` 和 `u_shared`；与软件 TB 的外部共享 RAM 接法不同 | 在最终网表确认完整层次和信号，不复用旧顶层名字 |
| 共享 SRAM | 64 个深度 bank，每 bank 四个 16 位宏，共 256 宏、512 KiB；bank 为字节地址 `[18:13]`，宏地址为 `[12:3]` | 最终网表展开后核对宏数、选择信号和实际输出 |
| SRAM 模型 | 官方公共 `RAMSP1024X16.v` 的物理数组为 256×64；宏地址低两位选列，数据位 b 位于物理位 `4*b+column` | 用原模型执行既有 `tb_xu_vendor_preload.sv`，检查全部 1,024 地址及四态 X 传播 |
| ITCM／DTCM | 固定配置均为 64 KiB，源码分别为 8×4 和 16×2 宏；加内部 17 宏，共期望 337 宏 | 对最终网表逐层确认实际实例名和数量 |
| 固件 | 紧轮询、分阶段 64、有限退避三份映像保持已验证 SHA | 在同一门级可执行件分别运行，保留完整退出和活动窗口 |
| 检查器 | 原 RTL 六处 CPU SVA、主 TB 52 条 fatal 和完整输出检查仍在冻结输入 | 适配门级可见信号并建立逐项保留映射；现阶段不能声称这些检查已在门级执行 |

PPA 顶层没有软件 TB 的额外 public fixture 端口。若采用厂商物理 SRAM 数组装载与读回，应明确记录为测试夹具初始化，在清零请求前完成；最终写响应退休后再读回。不得把这种装载记为实际公共总线传输，也不得对 CPU、DMA 或握手信号强制置值。实际 DMA 读写、全部 Y 输出、物理清零和固件返回仍须由真实 DUT 检查。

能耗记录需要同一最终网表、同一库、同一时间窗定义和完整 SoC 活动覆盖。旧 16 PE 工程只提供接口参考，旧功耗及理想时钟换算不填入本版结果。

# S3-Y32 第二轮：四项写回优化实测

2026-11-08。四项独立实验均已完成；选择 **加速器→NICE 内部取数通道**，12 层有效任务周期减少 **19.6517%**，计入物理参数清空后减少 **14.5385%**。多组 drainN 保留为独立备选；轮询退避与 CPU 循环展开没有完整任务收益。探索阶段未运行综合。

本轮执行范围见[计划](s3-y32-writeback-v2-plan.md)，接口及兼容性见[通道说明](writeback-v2/direct-channel.md)，原始日志摘录、逐层表及补丁见[证据目录](validation/s3-y32-writeback-v2-20261108/README.md)。这是一轮开发测量，不代表正式 PPA、STA 或赛题资格通过。

## 对照条件

基线是上一轮 read-pop：主仓 `562a8c91a42ba96c584c78c475fb972e6ac11d49`，E203 `6e2ec8995c92f97a0b1c45a3652f902ad43ef8e1`。选中候选 E203 为 `d74d520`。父子分支均为 `codex/s3-y32-writeback-v2`，原 main 工作区保留。

每个候选有独立源码副本和冻结 campaign。使用 RISC-V GCC 14.2.0、Verilator 5.032 `--assert`、150 MHz/32.768 kHz 外部时钟刺激、显式 `external-reset`、每层 fresh native process、相同输入和黄金输出、真实 CPU 参数清空。未改变 E203 LSU、BIU、仲裁或在途配置；CPU 两个文件仅传递新增端口。Y32、packed16、bias SRAM、8 PE、逐调用错误检查和内存顺序保证保留。

主指标为 payload（首 source request 至最后 Y 写响应退休）加 clear_cycles。clear 后 ABI 预检至首 source request 的 gap 单独报告；两组每层均为 102 拍，不藏入收益。12 层都核对 304,128 个输出，不冒充官方 600 样本模型精度验收。

## 内部通道为何有效

旧 drain8 每组至少有 1 次状态读、8 次结果 MMIO 读、8 次共享 Y 写，共 17 笔 LSU 总线事务。第一版 direct **保留真实状态查询及 poll_limit 语义**，只消除 8 次结果读，最低变成 9 笔，尚未达到只剩 8 次写的设想。

wrapper 逐拍捕获八个 lane，复用一个 RNE 数据通路，再发布原子 256-bit bundle 和组状态。NICE 收齐并寄存后，下一拍才提交一次 FIFO POP；其后八次共享写仍逐响应完成，最后响应之后才产生 completion。claim 排斥竞争 MMIO 结果读／POP，先前已接受的 MMIO POP 必须先退休。错误检查、组号检查、有界状态轮询、rd/OITF 退休、背压和中止语义保留。

新增 `DIRECT_CAP=0x59440001`（偏移 `0x0f0`）与 `DIRECT_CTRL`（`0x0f4`）。模式复位为禁用，固件在测量窗口内探测 capability 并启用，增加一笔 MMIO 写。旧 drain8 编码不变；旧 read-pop 固件在新 DUT 上单层通过，仍是 564,118 拍及全部旧精确计数。冻结旧宏／契约／运行参数的 336 个组合及六个加载镜像也已核对。

相同 hfclk、共同复位断言及 NICE 较晚的同步释放已沿层级审查；没有新增 CDC。若改为独立时钟或复位，必须重新设计该协议。direct bundle 或 commit 永久停顿与总线永久停顿一样可阻塞指令，poll_limit 仍只计真实已退休状态响应，并非握手周期超时。

## 12 层完整结果

每个原层号 0–11 均有同样的周期变化；完整逐层数字在 [layers.csv](validation/s3-y32-writeback-v2-20261108/layers.csv)。

| 指标 | read-pop | direct | 变化 |
|---|---:|---:|---:|
| payload cycles | 6,769,416 | 5,439,108 | −1,330,308（−19.6517%） |
| physical clear cycles | 2,380,836 | 2,380,836 | 0 |
| payload＋clear | 9,150,252 | 7,819,944 | −1,330,308（−14.5385%） |
| clear 后 gap（另列） | 1,224 | 1,224 | 0 |
| 输出／共享 Y 写 | 304,128 | 304,128 | 逐位一致 |
| NICE 请求／完成／OITF 退休 | 各 38,016 | 各 38,016 | 0 |
| 状态查询 | 60,588 | 60,588 | 0 |
| 结果 MMIO 读 | 304,128 | 0 | −304,128 |
| 内部 bundle／direct POP | 0／0 | 38,016／38,016 | 新通道精确计数 |
| MMIO 总读 | 364,728 | 60,612 | −304,116（每层多一次 capability 读） |
| MMIO 总写 | 147,948 | 147,960 | +12（每层启用一次） |
| FIFO 满等待 | 1,544,436 | 248,340 | −1,296,096 |
| compute/writeback 重叠 | 1,821,204 | 1,897,236 | +76,032 |

每层 writeback 为 297,795→193,252，占 payload 从 52.8%→42.6%。新 profile 从真实 direct claim 开始归入 writeback，旧 profile 仍从结果 MMIO 读开始；它包括取数、总线等待与共享写，不能视为纯共享内存写服务时间。另有 compute_wait 减少 6,336 拍／层，W/X/bias 装载阶段小幅变化。FIFO 满等待和重叠不是互斥阶段，不能与阶段周期相加。

严格报告器只在显式 `--allow-direct-transport` 下允许 read-pop→direct 单向比较；要求唯一宏、运行 selector 替换和精确声明的 11 个源码 SHA 差异。两侧工具、输入、时钟、启动、清空配方及其余命令仍一致。启用 capability 的固件有意变化，两侧生成的清零 C 程序仅归一化唯一已知 include 路径后逐字相同；两份 ELF 各自与其实际加载镜像独立核验，未声称镜像相同。完整 DUT/固件快照 170 个源文件与当前集成源码匹配。

## 另外三个方向的证据

**轮询退避。** 额外 1,881 次查询全部来自每行首组：99 行各 19 次空响应；后续 3,069 组均只查一次。参数 0/2/8/13 的查询数为 5,049/4,653/4,059/3,762。13 拍使查询减少 25.49%，但有效响应仍在相同拍到达，任务周期不变；2/8 拍错过可用时点反而更慢。0/2/4/8/13 各 61 个单元场景、817 笔事务及 17 个错误位置通过，4 拍仅做单元测试。没有功耗测量，不能由空读减少推断能耗改善。

**CPU 调度。** 被动测量 3,167 个 completion→next-request 间隔，其中同一行内 3,069 个均为 7 拍，合计 21,483；跨行 72,520 拍包含装载工作，不全是循环手续。展开 4/32 次将行内间隔总和降至 19,107/14,652，但其他等待抵消收益，完整任务分别 0/+14 拍。反汇编核对每个 custom 调用之后仍有 fence 和立即错误分支；未删除 memory clobber 或报错检查。

**多组搬运。** 独立 `funct7=0x21` drainN 接口支持同一行 1–32 组，旧 `0x20` 不变。每组重新使用独立 poll budget，地址／count／跨行限制、首次错误中止和末响应保证保留。以 read-pop 传输独立测试，NICE 请求／完成每层由 3,168→99；状态读、结果读及 Y 写未变。12 层 payload 6,511,620，加清空 8,892,456；每层减少 21,483 拍。97 场景、17,225 事务，包括 32 个组位置和 POP 后写错误通过。新增指令与直通通道合并尚未测试，因此只保存补丁，不并入选中版本。

## 验证、失败和交付

已通过 direct 的真实 MAC 32 组／256 lane，含边界与正负 ties，bundle／commit／completion 背压，19 个错误场景、所有九个总线错误位置以及四个 NICE 状态复位；wrapper 捕获／valid／owned 阶段复位均无陈旧 bundle 或 POP。原 read-pop 61 场景回归、旧七项 Icarus wrapper、SRAM capability 分支、S3 数值 11 项、固件合同 15 项、报告器 30 项和 campaign 15 项通过。额外 fresh-process 首请求等待 7 拍：453,266＝453,259＋7，窗口含首等待和末响应。

保留失败记录并区分原因：

- direct 最初两次 task0 数值通过，但旧阶段观察器只认结果 MMIO 读，无法开启 direct writeback，正重叠断言失败；仅补新 profile 的 claim 边界后重跑，通过原正重叠检查。两次失败未算 PASS。
- poll 首次多层 defparam 被 Verilator 拒绝，改为明确实例常数后才取得有效测量，保留原编译失败。
- 独立复查发现新增端口使九个旧 `dut(.*)` 夹具缺信号，已补禁用输入及输出 wire；生产代码未因此改变。七个常用 wrapper 和 SRAM capability 复跑通过。
- host gate 夹具可编译，但在当前 SRAM core 上触发响应断言；用未改 baseline wrapper 重现同时间同失败，未改断言，未计 PASS。register capability 分支缺少生成夹具，未运行。
- 原路线 VCS 测试因本机缺少 VCS 未执行；单独 Verilator 路线检查通过，不当作 VCS 证据。

源、数值、协议与报告入口已独立复查；本地 E203 与父仓分别提交，未推送。紧凑证据入 Git；完整 campaign、独立模拟器、源码／向量／ELF／加载镜像、失败原件及父子增量 Git bundle 位于工作树 `build/writeback-v2-20261108/handoff/`，README 和 SHA 清单随包提供。归档独立解包后 4,204 个文件／15 组 campaign 完整性核验通过，使用包内最终报告器严格复算仍得到 7,819,944 拍及相同逐层结果。

剩余正式验收由整机流程完成：VCS 原厂 SVA、厂商 SRAM 门级、150 MHz setup/hold、等价范围、同库净面积、全 SoC 能耗和清空政策。新增 256-bit 源快照、寄存器、lane mux 和宽连线有面积／时序代价；复用 RNE 的实际映射尚未综合。Verilator 二态开发 PASS 不关闭这些项目，也不证明 baseline 既有时序违例已经消失。

# S3-Y32 后续数据流优化 goal

2026-11-08。用户授权制定 goal 并完成。基线父仓 `83817c8`，E203 `d74d520`；实验分支 `codex/s3-y32-postflow`。保持 11 月 13 日交付、11 月 11 日冻结；探索阶段不综合，不推送。

## 执行范围与判定

| 工作 | 可复查完成标准 |
|---|---|
| 批量接收16、收齐再写 | 采用既有256位通道两次8结果握手，一次NICE请求；两次POP完成前零Y写；保留旧drain8，新增独立编码；单元错误/背压/复位、真实MAC wrapper、8/16PE同条件单层 |
| 偏置连续读取 | 24个16bit SRAM word 连续issue及相邻拍capture；不改变1RW宏、host mask/响应/clear；覆盖epoch失效、尾返回、复位、全部组及INIT稳定性；8/16PE独立对照 |
| 组合与选型 | 单变量与组合分别测量，不相加收益；选中候选完整12层输出逐位回归，全部原错误/末响应/退休/窗口检查保留 |
| 双缓冲与搬运瓶颈 | 通过被动状态/事务计数区分写服务、等待、取数和CPU调度；判断新增缓冲是否能解除真实阻塞，给出实施或暂缓依据 |
| 两行×八列与DMA | 依据当前矩阵形状、地址步长、总线服务测量给出具体架构、缓冲/尾行/所有权成本；未获吞吐证据不引入大规模接口改造 |
| 41位内部累加 | 用完整signed16/signed40/K64数学界及任意前缀界验证无损可能性，明确不能缩为40位；不宣称未测的面积/能耗收益 |
| 交付 | 独立审查、最终集成源SHA与测量快照核对、限定回归、本地提交、失败原件/补丁/复现及回退证据 |

后四项按证据给出推进或暂缓结论；本轮不以大范围架构重写代替已明确可测试的前两项。选型以实际效果决定，允许保留8PE基线。

## 共同条件

- 8PE direct：payload453259、clear198403、gap102；16PE pair/drain8：payload469191、clear198403、gap102。
- Verilator5.032二态开发、`--assert`、150MHz/32.768kHz刺激、external-pad-double-reset、RV GCC14.2、每层fresh process、相同向量与真实物理清空。
- Y32数值、INT16乘法、现有外部协议与错误检查保持；不改E203 LSU/BIU/仲裁/在途配置。32位共享总线仍逐笔写，不把批量指令说成16字同拍写。
- 主要指标payload＋clear，gap另列；阶段与重叠量分开。面积/能耗/STA及正式VCS/门级资格不由开发周期仿真代替。

## 结果与冻结

完整12层304,128个输出逐位通过。原版payload＋真实clear为7,819,944拍，最终为7,537,200拍，净减282,744拍／3.6156788%；每层429,697＋198,403。选中方案保留8PE／256位内部通道／32位共享总线和原drain8 ABI。16结果批量接收及16PE组合无全任务优势，不集成。独立严格比较和20项损坏证据负例全部完成，170个测量输入SHA与最终集成源码一致。

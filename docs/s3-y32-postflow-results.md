# S3-Y32：后续数据流优化结果

日期：2026-11-08 至 2026-11-09。用户授权的 goal 以[计划](s3-y32-postflow-plan.md)执行。选中 **8 PE＋逐组流式 NICE＋偏置 SRAM 连续读取**；单层 payload 从453,259降至429,697，计入清空从651,662降至628,100，分别减少 **5.1984%／3.6157%**。这两项组合是直接实测，未相加推算。

当前保留8PE、原256位内部结果通道、原8lane快照及32位共享总线。未运行综合，新增面积、时序、能耗和正式资格仍待整机验收。

## 同条件与基线

父基线 `83817c8`，E203 `d74d520`；父子实验分支 `codex/s3-y32-postflow`。原8PE direct全12层基线每层payload453,259、clear198,403、clear后gap102；已通过16PE pair/drain8单层为469,191＋198,403。所有比较使用同一冻结原层输入、golden输出、RV GCC14.2、Verilator5.032 `--assert`、150MHz/32.768kHz外部时钟刺激及external-pad-double-reset。每层fresh native process，真实CPU执行相同物理参数清空。

没有改变E203 LSU/BIU/仲裁/在途配置、CPU控制、direct wrapper、共享SRAM模型、数值模型或量化方式。Y32、packed16、bias单口SRAM、所有错误返回检查、fence及memory clobber保留。原始日志、源码SHA和复现材料见[证据目录](validation/s3-y32-postflow-20261109/README.md)。

## 选中方案的具体行为

**逐组流式搬运。** 新独立指令 `custom3/funct3=7/funct7=0x23` 可在同一行处理1–32组。每组仍执行真实状态读→接收8lane→下一拍commit一次POP→八次32bit共享写响应；第八次响应退休后才转下一组，最后一组末响应之后才completion。复用既有8个snapshot，没有加宽内部通道。

rs1为32B对齐Y地址。rs2的group占[4:0]、count_minus1占[9:5]、非零每组poll_limit占[31:10]。要求组范围和完整目的span留在一行、目的行内offset等于group×32；新组合范围错误为9，旧1–8不变。每组重装poll budget，仍只计真实已退休状态响应。任何错误立即中止整个指令／任务；已POP或部分写入不能盲目retry。

CPU每行提交一次count32，从3,168次请求／完成／OITF退休降为99。单层仍3,168个bundle／POP和25,344个Y写。只减调度手续，不减真实计算与输出工作。stream单独版本净省21,483拍，恰等于99行×31个组间间隔×7拍；这是同条件实测，不作为任意总线配置下的保证。

旧0x20 drain8保留原编码、范围、group/poll含义和错误码。新 `XU_NICE_DRAINN=1` 必须与direct/DRAIN8宏配套，poll上限为22bit，fence、memory clobber和非零返回立即中止保留。宏关闭时固件加载binary与旧版相同。现有DIRECT_CAP没有单独标识0x23，部署必须以父gitlink锁定匹配NICE／固件版本；不能仅看旧cap就判定任意旧DUT支持新ISA。

**偏置流水读取。** 单口1024×16 SRAM每组仍读取24个word；原先issue/capture交替48个周期，新groupStream连续24拍发读并接收前一拍返回，第25个周期收齐word23后才置slotValid。新增流水控制寄存原始约6bit，host读写、byte mask/RMW、返回背压、仲裁和物理clear路径保持。

invalidate或epoch过期优先取消新issue与在途return，不发布部分槽，已接受demand随后重试。groupTake只针对完整当前epoch结果；INIT采样前偏置稳定性仍由调度器保证。其8PE独立收益只有1,393拍，说明大量预取已经被计算隐藏。与stream组合后总净省23,562拍，并非独立收益简单相加。

## 被动测量与其他路线判定

被动probe不驱动DUT信号，在新增计数下完整复现原453,259＋198,403拍。

| 测量 | 原8PE direct |
|---|---:|
| Y命令／响应 | 25,344／25,344 |
| 端点接受命令至响应退休（inclusive） | 每字恰2拍 |
| NICE WAIT_WRITE | 139,394拍，约5.50拍／字 |
| Y命令端点背压 | 12,676拍 |
| direct claim | 34,848拍 |
| bundle有效后等ready | 0拍 |
| 有空槽却等biasReady | 5,742拍 |

端点2拍和NICE等待5.5拍包含不同范围、存在包含关系，不能相加。shared端点接受请求共40,384，占payload拍数约8.91%；这不是全SoC所有链路利用率，也不能直接推算DMA加速比。

- **结果FIFO四槽／X双缓冲：暂缓。** 四槽需新增768bit结果payload、指针计数和读mux；rowCount从2位变3位还影响旧ROW_STATUS布局，必须新cap或独立状态表达。局部FIFO满等待不是可直接消除的周期。X双缓冲需新的行所有权及原子切换，不能简单取消运行期间参数保护。先交付已有收益的控制解耦。
- **DMA／专用写回引擎：暂缓。** 测量支持排查串行接口开销，未证明共享端点饱和。新master还需仲裁、响应归属、末写可见性、错误和复位验证，并可能越过本轮不改fabric的边界。本轮不实现、不宣称速度收益。
- **两行×八列16PE：模型评估完成，暂缓RTL。** 两行共享八个W和bias，50对行含尾行mask需102,400个MAC有效周期；一行×16列为101,376。权重片内16bit读取从1,622,016降至819,200，但不自动减少整层W上传。需额外128B X行buffer及两个X读取；两行Y地址相距1,024B，需要带stride调度或额外1KiB第二行结果缓存。约半片内读取不等于约半周期。
- **41位内部累加：完整域界验证完成，暂缓集成。** signed16×signed16、signed40 bias、0–64任意前缀范围均落在signed41；终值为[−618473193472,618475290623]，signed40不够。可在出口符号扩展保留48位接口。八个ACC仅原始寄存位由384降328，节省56bit；未综合前不宣称面积、时序或能耗改善，也不把随机回归替代完整界证明。
- **真实清空效率：暂缓接口改造。** clear占原总周期约30.4%，硬件清空序列器值得后续研究，但需重新验证所有物理字、末写退休及政策。当前候选保持相同真实清空，不能用logical invalidate或跨任务驻留参数冒充清零。

以上明确区分已实施／实测与架构模型，未把暂缓路线算作硬件优化成果。

## 验证和保留的失败

- 新stream单元118场景：count1–32、32个status失败组位置、第二／中／末组的8个写错误、每组poll重置、14个复位状态、cap禁用、descriptor范围／rowoffset及背压；另编译时禁用及旧direct19场景通过。
- 真实MAC wrapper完整32组／256lane、独立RNE oracle、数值端点／正负ties、bundle/commit/completion背压、组7写错误后立即停止、三个wrapper复位阶段通过。
- 偏置全部32tags、每fill精确24次连续地址／25stream周期、25个invalidate边界、25个reset边界、8,192 byte masks、host仲裁／背压、768word真实clear通过；限定Chisel BiasSramPrefetchTest通过。
- 主树新旧stream/direct/read-pop回归、17项固件契约、11项S3数值、15项campaign和30项历史报告器测试通过；独立postflow比较器负例检查工况、镜像、clear程序、源码及marker篡改均拒绝。
- 保留fixture失败：偏置新测试最初同delta检查ready，补settle后通过；batch16旧40次producer查询预算不足与physicalgroup步进不匹配已修正，未改DUT或删数值断言；stream复位fixture初版遗漏合法rs2 descriptor而未进入目标状态，修复后通过。
- 16PE bias首次使用8PE runner漏存结构化PE16字段，作为diagnostic保留；正式版用原16PE runner重跑，source唯一变化BiasSV，周期相同。
- 被动probe准备首次实例名错误而拒绝生成；第一份未加probe运行只复现基线，正式transport-observed运行才含被动计数。campaign mock首次缺新schedule常量，修正仅测试fake后通过。

这些失败的原始日志均保留，未算PASS。开发仿真为二态、vendor SVA关闭，Chisel过程断言通过`--assert`保留，外部显式复位；正式VCS、厂商SRAM门级、STA、面积及单任务能耗尚未完成。

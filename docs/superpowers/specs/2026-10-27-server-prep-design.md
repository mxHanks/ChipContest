# C 角色服务器接手准备

目标：在官方服务器下发前，把现有开发平台成果变成可离线搬迁、可一键重新验收的交接物。用户已授权将能完成的前期工作直接做完；本次继续自主实施。

沿用 Python 标准库和已有 E203 运行器，保留硬件、ABI、依赖版本及现有真实夹具。仅补充独立的整数向量核算、实际工具链/子模块预检、顺序执行的验收入口及 Git 原生离线包。复用现有回归比增加第二套仿真框架更易维护；官方宏接口未知，暂时编写假宏或猜测工艺脚本不能产生有效验收。

交付判据：12 层真实夹具逐元素符合 XW+b；坏参考值被拒绝；预检实际构建 RV32 固件并拒绝缺失/错误子模块；验收任一步失败即失败并保留日志；完成一层 Icarus 四态回归；两个仓库的 bundle 在无远程访问的新目录恢复并重新运行检查及真实单层仿真。离线包清单固定提交和文件 SHA256，不含本机凭据或专有工艺库。

全部提交在新分支 feature/e203-server-prep。官方 SRAM、150 MHz、面积/功耗、官方600样本精度仍须官方材料；文档明确输入、验收标准及接手顺序。当前四态开发验证不替代门级/工艺验证。

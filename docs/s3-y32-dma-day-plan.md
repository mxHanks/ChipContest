## 执行顺序与门槛

1. 测真实外围接入口、仲裁和共享 SRAM 的 W/bias 8704 字及混合流 31680 字吞吐；记录接受间隔、延迟、停顿、所有权和复位。先使用单在途。
2. 实现 8 个独立 W bank 并行物理清零，与 bias、四个 X 行缓冲并行；脏前态逐地址和寄存器观察。目标不超过 3000 拍。
3. 复用双 8 PE 核，共享一套 W/bias；4×64×16 X ping-pong 总量 512 B，块结果和背压；第 99 行关闭第二路。W packed32 同时写两个独立 bank。
4. CPU 提交冻结地址、clear、start、轮询错误与完成，提交和读取间使用 fence。所有 Y 响应退休及在途排空后才能完成；首次错误终止任务、不重试部分写回。
5. 协议/数值模块 → 真 CPU 单层；正确且有收益才做完整 12 层。同一搬运路径分别单行、双行，对照原 8 PE。
6. 完整输出逐位核对、逐层计数及周期、真实清零、参数身份、异常/背压/复位、旧响应隔离、源码/ELF/工具身份。最后至少两小时优先验证、核验和打包，停止扩大功能。
7. 仅完整功能和周期支持选型时再考虑集中一次同库综合；缺少面积或 STA 则明确未测，不使用旧证据。
8. 本地父子提交、必要补丁、复现包、所有失败与否决原因；不 push、PR 或外发。

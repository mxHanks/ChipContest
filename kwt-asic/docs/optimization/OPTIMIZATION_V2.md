# AI Engine 第二轮：双行复用与结果写回重叠

2026-10-15。保留 migration-v0.2 和第一轮候选，新加 `src/rtl/kwt_linear_engine_rowpair.sv`。已验证的是独立 new-KWT 功能、核心周期和保留 RAM 的综合结构；尚未获得指定工艺的面积、150 MHz 时序、功耗或 E203 完整任务窗口结果。

## 同 16 个 MAC 的实测对照

以下使用同一组 12 个合成任务，无输出回压。每项均处理完整 `99×64×256+b` 并逐位核对全部输出；计时从核心接受 start 到最后输出握手，**不包含 E203/总线/系统写回确认**。对照报告重新核对了原始日志和所有源文件、输入 SHA。

双缓冲流水候选比单行16列流水少16.62%核心周期，比原8路基线少53.17%。单缓冲双行版本反而比单行16列慢：权重复用本身没有消除输出串行排放的时间，收益需要计算与写回重叠。流水候选比未流水多1,600拍；最终选择仍须按指定150 MHz的实际时序和全窗口能耗决定。

## 实现及成本

- 两个独立X bank同时供给相邻两行，8组W/bias广播给16个MAC。第99行关闭第二行的读取、乘积寄存、累加和结果写入。
- 内部累加/结果缩至41位，接口仍输出48位符号扩展。对所有合法16位X/W、40位bias和任意0–64项部分和，范围严格在signed41内；不会改变fixed16_acc48_v1的结果。另跑极大正/负点积，覆盖signed40不能表示的结果。
- 每tile先捕获16×41位快照，后台每拍写一个结果；16拍存储隐藏在下一个tile的64拍计算中。每对行最后等待16拍写尽，尾行等待8拍，随后该buffer才可输出。
- 每个结果buffer只有一个512×41同步RAM。两个buffer分别写入/输出，单个buffer不同时读写；两个输出预取槽计入在途读请求，支持连续每拍输出并保持回压稳定。DONE由最后一个输出握手产生。

最初考虑的16路浅bank并行写入会将双结果缓冲映射容量扩大到24 KiB；已改为快照后台串行写，按指定128×16宏宽度/深度取整后，两组共6 KiB。当前双行双buffer完整存储容量候选是**56.5 KiB、72个SP宏**，与单行16路的56.5 KiB同容量但不同宏组成。实际面积不能从容量相等推断。

| 每任务逻辑活动 | 单行16列 | 双行8列 | 说明 |
|---|---:|---:|---|
| X读，16位字 | 101,376 | 202,752 | 双行方案X读翻倍 |
| W读，16位字 | 1,622,016 | 819,200 | 减少49.495% |
| bias读，40位字 | 25,344 | 12,800 | 减少49.495% |
| 结果RAM写/读，41位字 | 0 / 0 | 25,344 / 25,344 | 新增内部活动 |

读量不是功耗。还必须计入快照、预取、地址选择、时钟、宏外围和接口。双行双buffer流水结构有2,086位非存储读口寄存器，单行16列流水为1,380位；没有以“W读减少一半”代替整机能耗结论。

## 证据覆盖

18组RTL回归、116个完整任务、2,939,904个逐位核对输出全部PASS：四种流水/缓冲组合的12任务对照、随机回压、首输出6000拍长停顿、队列耗尽、三类在途/输出复位、非法装载、Icarus四态、signed41范围极值，以及同一真实非静音语音的12层参数回放。第99行、最后输出、结果读写守恒和持续ready无组内输出气泡均检查。

四组Yosys结构综合全部PASS：1/2组结果buffer分别保留19/20个独立同步1R/1W逻辑存储，精确核对X/W/bias/结果bank的深度和宽度、16个signed16×16→32乘法器；无多端口合并或异步读警告。保留载荷为394,752/415,744 bit。仍无指定宏映射、标准单元映射或综合前后等价证明。

软件精度另已完成原版采样的4,445条validation：最大层NRMSE为0.0132799%，最差样本层为0.0195401%，0裁剪；见[数据验证](DATASET_EVALUATION.md)。全验证集软件通过不等于全量RTL回放，更不等于官方冻结后的600样本评测通过。

## 剩余瓶颈及下一步

1. 当前16位数值误差余量很大，继续评估减少X/W有效位数；同时算精度扣分。官方每0.3个百分点扣1分，不能把“刚低于3%”当最优作品。
2. bias并行bank的宏填充仍有浪费；可研究集中存储与跨tile预取。结果缓冲的串行后台写已经避免一项明确容量浪费。
3. 取得指定宏模型/面积/功耗和标准单元库后，映射同一组配置并分析关键路径。面积必须加上新增接口、宏选择逻辑和全部内部SRAM，严格小于2.25 mm²。
4. 由E203集成方提供总线/NICE与地址图，按从参数/输入装载到最终写事务确认的12任务窗口测吞吐与功耗。新[PPA证据检查器](PPA_INPUT_CONTRACT.md)拒绝漏项或混用网表，但它不会代替EDA生成物理结果。

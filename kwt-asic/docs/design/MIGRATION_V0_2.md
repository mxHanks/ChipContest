# migration-v0.2：第一前馈线性层功能首版

日期：2026-10-15，Asia/Shanghai。v0.1 完成环境、来源校验与长期执行入口；本版增加**实际计算的 KWT 形状线性层 RTL、候选位级数值模型和完整矩阵仿真**。已通过下述合成向量与协议检查，真实模型精度、E203 集成和指定工艺验收需要各自独立证据。

## 已实现的算子与接口

`src/rtl/kwt_linear_engine.sv` 实现 `Y[99,256] = X[99,64] × W[64,256] + bias[256]`。默认8个乘加lane，按99行、32个输出通道块和64个输入维度循环。`LANES` 必须是1..256中256的正约数；本页两份仿真报告均验证默认8lane，不代表其它合法配置均已验证。

- **装载**：`load_valid/load_ready`、kind/address/data接口，kind 0/1/2分别对应X/W/bias。每种张量独立从地址0严格递增，分别收齐6,336、16,384和256个字后才允许启动。X/W取40位输入口的低16位，bias取完整40位；地址均为逻辑行优先索引。
- **控制**：启动必须握手；计算和输出期间拒绝新装载/启动。非法kind、非法地址或重复/乱序地址触发sticky error，复位清除。完成后装载计数归零，下一任务重新完整装载，避免旧参数被当成新任务有效数据。
- **计算**：同步读X和分bank的W/bias，first/last标记随读数据对齐；硬件自行乘加。每个输出块计算完成后按lane顺序输出，随后进入下一块。当前实现不重叠装载与计算，也不重叠下一块计算与当前块输出。
- **输出**：`out_valid/out_ready`、48位结果、15位行优先索引和最后一字标记。回压时保持数据、索引、last稳定；第25,344个输出被接收后，`done`脉冲置位并回到空闲。输出是独立DUT流接口，尚未通过E203总线写入共享SRAM。
- **复位**：清控制/有效性状态，不批量复位payload RAM。新任务必须完整重装才可开始，内存残留内容不能直接构成有效任务。

文件入口：软件模型 `model/fixed16_acc48.py`，数值单测 `tests/test_numeric_model.py`，testbench `sim/tb_kwt_linear_engine.sv`，运行器 `scripts/verify/run_linear.py`。testbench负责装载、回压、复位和结果核对，不代替DUT完成必做计算。

## 如何复用 FPT

原始 `vendor/fpt-r1/` 保持字节不变。本版借鉴FPT的ready/valid所有权、同步存储读与标签对齐、payload RAM不清零而由有效性约束保护、完成前持有输出、明确向量和完成标记等方法。新模块没有实例化FPT算术核、AMD浮点/XPM、因果掩码、GQA或DDR控制逻辑。

原QK调度包含128维、32lane、head/group和因果关系，直接修改参数无法得到99×64×256+b。因此本版重新建立前馈矩阵循环、偏置、输入/权重布局和输出索引；原FPT局部PASS只作为复用参考，新算子的PASS来自本版DUT单独执行。

## 候选数值格式

`fixed16_acc48_v1` 为本次功能基线：X/W为有符号16位、bias为有符号40位，64项整数乘积精确累加并输出有符号48位，MAC中间不舍入、不饱和、不截位。任意部分和绝对值不超过 `2^39 + 2^36 < 2^40`，合法输入在48位累加器内安全。

浮点转换用显式2的幂尺度，`real = code × 2^exp`。X和W各有一个尺度指数；bias/Y使用两指数之和。编码按RNE（最近偶数）后饱和，非有限输入拒绝。软件按层累积误差平方和、参考平方和及元素数，再计算NRMSE，分母RMS下限为1e-8，不平均每个样本的NRMSE。完整定义见 `docs/design/NUMERIC_CONTRACT.md`。

这个候选格式便于先检查硬件数学与协议，**不是永久格式冻结或真实KWT精度达标结论**。输入尺度仍需有依据地选择；候选格式和每层配置须由真实权重、对应层输入、误差及后续PPA结果评估。

## 内存与周期含义

当前片内逻辑payload容量：

| 内容 | 逻辑容量 |
|---|---:|
| X，6,336×16位 | 12,672字节 |
| W，16,384×16位 | 32,768字节 |
| bias，256×40位 | 1,280字节 |
| X/W/bias合计 | **46,720字节，45.625 KiB** |

默认8lane时，W分成8个2048×16位bank，bias分成8个32×40位bank；逻辑W[k,c]映射为bank `c%8`、bank地址 `k×32+c/8`。输出逐字流出，仅保留一个8lane累加块，DUT没有整幅输出RAM。若外部存放完整Y，需25,344×48位=152,064字节（148.5 KiB）；X/W/bias/Y紧凑编码总量为194.125 KiB。这是容量推导，不包括对齐、总线包装、宏深度取整和平台保留空间，不能据此确认最终SRAM实例、地址图或面积。

当前存储仍为可推断的同步RTL数组，**尚未替换为组委会指定SRAM宏**。40位bias需要适配16位宏组合，bank数量和深度也需根据指定宏及端口约束调整。未映射到实际工艺前没有2.25 mm²面积或150 MHz时序结论。

默认8lane无输出停顿时，源码时序推导为：

```text
99行 × 32通道块 × (64个发读/MAC节拍 + 1个末乘积排空拍 + 8个输出拍)
= 231,264 core cycles / task
```

本轮主回归core周期总计2,819,087；减去12×231,264恰好为43,919，与报告输出停顿周期一致。`core_cycles`从启动被接收后计到最后输出被接收，包含输出停顿，**不包含输入/参数装载、E203调度及总线等待**。testbench另统计的3,112,289拍窗口包含其装载/启动/输出/检查开销，同样不是比赛计时。正式吞吐与能耗须在真实SoC从输入/参数开始装载到全部写回的统一窗口重新测量。

## 真实checkpoint与静音回放补充

`scripts/model/export_kwt.py`已在固定上游模型上实际运行。除`assert_existing_objects_matched`之外，将恢复模型重新保存并逐键逐值核对全部162个模型变量与原checkpoint完全相等，仅忽略优化器状态。上游跟踪别名警告保留；完整变量比对避免用未恢复的随机权重生成参考。使用上游原图模式和Keras backend取值，未修改vendor文件。

一秒全零波形按上游代码生成98×40 MFCC；脚本观察每层第一前馈Dense的真实调用，取对应Attention+残差+第一LayerNorm后的99×64输入。12组实际W均为64×256，bias长度256。量化X尺度只由LayerNorm gamma/beta理论界选取，W尺度由权重绝对值界选取，均用最小安全2的幂尺度；不按静音结果反调。全12层X/W/bias裁剪数为0；相对实际TF Dense输出的最大层NRMSE为0.0001951081066091623，即**0.0195108%**，仅此静音单样本。

证据：`docs/runs/kwt-silence-export.json`及原日志；可搬迁回归输入在`sim/vectors/kwt-silence-v1/`。`make linear-real`重新核对checkpoint/source/向量SHA、12层顺序、软件完整golden后，在真实DUT中重算12任务304,128个输出，最新回放**PASS，5.157秒**，报告为`docs/runs/linear-real/result.json`。显式`--source-root`支持新工作区路径，仍要求同一源字节。

上述推理环境是Python3.8.20、TF CPU2.4.0、NumPy1.19.5。上游要求的2.4.0rc1本次PyPI不可得；正式版替代差异已记录，正式评估前需继续核查。这份静音结果不是Speech Commands验证集精度，也不是官方600条评测或正式12个性能任务通过。

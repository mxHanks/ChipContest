## 核心运算与任务边界

本科必做为前馈网络的**第一线性层**：

```text
Y[99, 256] = X[99, 64] × W[64, 256] + b[256]
Y[r, c] = b[c] + sum(k=0..63, X[r, k] * W[k, c])
```

一项线性任务包含 25,344 个长度 64 的点积，即 1,622,016 次乘累加和相应偏置处理。这是运算量推导，不是实际周期预测。输入 X 必须是对应编码器层注意力、残差及第一处 LayerNorm 之后的前馈输入；不能把 99×64 的首层编码器原始输入直接用作所有 12 层的前馈输入。各层的前馈输入由指定浮点模型离线提取，本科硬件无需先完成注意力。

数值门槛的实现公式（逐层汇总，不先平均各样本 NRMSE）：

```text
NRMSE[layer] = sqrt(mean((decode(Y_hw_model) - Y_float)^2))
               / max(sqrt(mean(Y_float^2)), 1e-8)
max_layer_NRMSE = max(NRMSE[0], ..., NRMSE[11]) <= 0.03
```

这里的 `mean` 覆盖该层全部评测样本的全部输出元素。12 个性能任务另有**每次单独 ≤3%**的要求（第 11 页）。开发阶段选择的整数/BF16/FP32格式，都必须经过真实层输入与权重的误差评估；不能由格式名称推断合格。

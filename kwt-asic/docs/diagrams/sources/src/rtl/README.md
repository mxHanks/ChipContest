# KWT-1 第一前馈线性层 RTL 首版

`kwt_linear_engine.sv` 实现固定形状 `Y[99,256] = X[99,64] × W[64,256] + b[256]`。
当前为独立计算引擎：完整装载、同步存储读取、乘加、偏置、回压输出和任务退役已实现。
真实模型误差、E203、指定 SRAM、150 MHz 时序、面积和功耗需要各自的验证证据；本模块的功能仿真不能替代这些验收。

## 数值和参数

候选契约名 `fixed16_acc48_v1`。X/W 是有符号 16 位二补码，偏置是有符号 40 位，输出和累加器是有符号 48 位。
每个输出按 `k=0..63` 顺序精确累加 32 位有符号乘积并加偏置；不进行中间舍入、截断、饱和或重定标。
所有合法 16/16/40 位输入组合的数学结果均可由 48 位表示。
加载 X/W 时只使用 `load_data[15:0]`，高 24 位不参与数值；加载偏置时使用全部 40 位。
浮点量化尺度、偏置对齐和输出解码由软件数值契约决定。这里的整数正确性不自动证明真实权重/输入满足 3% NRMSE。

只有 `LANES` 可配置，默认 8；取值须为 256 的正因数。矩阵维度固定，不能通过修改参数缩小测试后声称全形状通过。
默认每周期发起 8 个输出通道的乘加，完成 64 项后串行输出该组 8 个结果，再处理下一个通道组。

## 装载和启动协议

所有接口在 `clk` 上升沿以 `valid && ready` 握手，`rst_n` 为异步低有效控制复位。

| 信号 | 含义 |
|---|---|
| `load_kind[1:0]` | 0 为 X，1 为 W，2 为偏置；3 非法 |
| `load_addr[13:0]` | 元素地址，非字节地址；每类独立从 0 严格递增 |
| `load_data[39:0]` | X/W 取低 16 位，偏置取全部 40 位 |
| `load_ready` | 仅在空闲、无错误且 `start_valid=0` 时为 1 |
| `start_ready` | 空闲、无错误，且 X/W/b 分别收到 6336/16384/256 个合法元素后为 1 |
| `busy` | 从启动握手之后保持为 1，直到最后输出握手之后为 0 |
| `done` | 最后输出握手后为 1，持续一个时钟周期；没有 done 反压 |
| `error` | 非法装载握手导致的粘滞错误，只有复位可清除 |

三种载荷可交错，或按任意类型顺序装载，但同一类型必须连续地址递增。
X 地址是 `r*64+k`，W 地址是 `k*256+c`，偏置地址是 `c`。
装载握手遇到非法 kind、跳号/重复地址或越界地址时，该元素不写入存储、不增加计数，并置 `error=1`。
错误状态会拉低装载和启动 ready，必须复位并完整重装后恢复。
W 地址端口最大为 16383，已经覆盖全部 W；额外装载即使地址回到 0 也会触发错误。

`start_valid` 可以在 `start_ready=0` 时等待，不因此产生错误；但 `start_valid=1` 同时会阻止装载，主机应先完成全部装载再保持启动请求。
启动和装载同周期出现时，启动有优先权，装载不会握手。
运行中装载和启动均不被接收，输入无握手不会改变数据或产生错误；调用者仍须遵守 ready/valid 的保持规则。
每次任务完成后，三类装载计数均清零；下一层必须完整重装 X/W/b，防止旧层参数污染。

## 输出、复位和计时

`out_data[47:0]` 是二补码结果，`out_index[14:0]` 严格依次为 0..25343，对应 `r*256+c`。
仅最后一个有效输出的 `out_last=1`。`out_valid && !out_ready` 时，输出数据、索引、last 和 valid 全部保持。
输出无效时数据和索引不作约定，不应读取。复位会中止在途任务并清除控制/valid/计数/错误；不清除大型 RAM 或累加寄存器。
复位后完整装载要求确保任何旧存储内容不会发布为有效输出。

`core_cycles` 在启动握手时清零，累计之后每个 busy 周期，包含输出等待以及最终输出握手周期；完成后保持直到下一次启动或复位。
达到 `0xffffffff` 后饱和，不能把饱和值解释为精确长等待时间。
无回压时预计 `99 * (256/LANES) * (65+LANES)` 周期；默认 8 路为 **231264 周期**。
64 个读取发起周期加一个末项排空周期，再加每组 LANES 个输出握手。
这个计数不含装载、E203 调度和外部写回，只能作为计算核心统计，不能作为赛题端到端性能。

## 存储和综合边界

内部 X 为 `6336×16` 位；W 按输出通道分为 LANES 个 bank，总计 `16384×16` 位；偏置同样分 bank，总计 `256×40` 位。
默认 8 路的每个 W bank 为 `2048×16`，每个偏置 bank 为 `32×40`。
逻辑载荷存储共 373760 位，即 46720 字节（45.625 KiB），不含读取/累加/控制寄存器及物理宏取整开销。
每个 bank 每周期同步读取一个元素；行、归约维和通道组寄存器产生读取地址，读数据与 first/last 标志对齐，下一周期进入乘加。
装载和计算互斥，不依赖读写碰撞的未定义行为。这里使用推断数组，尚未实例化指定 SRAM 宏；偏置 40 位需要未来映射时拆分宽度。

综合文件集只应列出本模块及以后明确新增的模块；不要递归编译 vendor，不要加入 FPT 的 FP32/XPM 仿真 mock。
本轮仅检查可综合语言结构和仿真行为，工艺映射与时序收敛仍待平台材料。

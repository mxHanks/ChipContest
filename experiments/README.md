# 实验实现导航

当前生产候选的验证与性能实现为 **[s3-y32-ingress-perf](s3-y32-ingress-perf/README.md)**，建议通过根目录的 `tools/current.py` 调用。候选身份与最终证据由 [submission/candidate.json](../submission/candidate.json) 选择。

其他目录记录历史候选、对照或被复用的实现依赖。其中 `s3-y32-compliant32/numeric/` 提供独立整数验证，`s3-y32-4k/core/` 等保留生成源，不能整目录删除。各旧 README 的架构和结果只适用于其当时版本。

评审与复现路径见[仓库首页](../README.md)，历史阶段关系见[历史导航](../docs/history/README.md)，新运行产物写入未跟踪的 `build/`。
